# 레퍼런스 분석 분류 체계

시각 레퍼런스를 일관되게 분석할 때 사용한다. 사용자-facing 분석은 한국어로 작성한다.

## 1. 타이포그래피
- serif / sans / grotesk / geometric / monospace / display
- 제목 상대 크기
- 굵기 범위
- 자간
- 행간
- 대소문자 사용
- 글꼴 개수
- 강조 방식
- 텍스트 위치
- 캡션 처리

가능하면 측정 가능한 문장으로 쓴다. 예: `대부분 제목은 2~4줄`, `본문은 대부분 25단어 이하`.

## 2. 레이아웃과 구성
- 대칭/비대칭
- 주요 정렬 방식
- 컬럼 수
- 여백
- 가장자리와의 거리
- 겹침
- 의도적 크롭
- 이미지:텍스트 비율
- full bleed 사용
- 프레임/카드 사용
- 반복 템플릿

## 3. 색
- 배경 밝기
- 채도
- 대비
- 강조색 개수
- 중립색 사용
- 팔레트 일관성
- 색이 위계를 만드는지 장식 역할인지

신뢰할 수 있는 샘플링이 아니면 정확한 HEX 값을 추정하지 않는다.

## 4. 이미지
- 사진/일러스트/3D/콜라주
- 연출/자연스러운 장면
- 클로즈업/와이드
- 카메라 각도
- 피사체 분리
- 배경 복잡도
- 조명 부드러움
- 채도
- 그레인/질감
- 크롭 패턴
- 누끼/컷아웃
- 테두리/아웃라인/그림자

## 5. 시각 모티프
스티커, 화살표, 낙서, 하이라이트, 라벨, 그리드, 구분선, 숫자, 아이콘, 도형, 종이 질감, 테이프, UI 스크린샷, 손글씨 마크 등.

## 6. 정보 위계
- 가장 먼저 보이는 요소
- 제목의 지배력
- 읽는 순서
- 슬라이드별 텍스트 양
- 한 슬라이드에 한 아이디어인지 여러 아이디어인지
- 번호 사용
- 요약 슬라이드
- CTA 처리

## 7. 카피와 편집 리듬
- 문장 길이
- 질문형/진술형 제목
- 대화형/설명형 톤
- 펀치라인 패턴
- 문장 파편 사용
- 괄호 사용
- 문장부호 스타일
- 슬라이드별 밀도

## 8. 캐러셀 시퀀싱
- 커버 방식
- 속도 변화
- 반복되는 슬라이드 리듬
- 시각적 리셋 슬라이드
- 텍스트 중심/이미지 중심 교차
- 마지막 CTA/요약 패턴

## 신뢰도
- `높음`: 많은 레퍼런스에서 반복됨
- `중간`: 분명히 보이나 샘플 수가 제한됨
- `낮음`: 신호가 약하거나 레퍼런스 간 충돌이 있음

낮은 신뢰도의 관찰을 강한 규칙으로 만들지 않는다.
