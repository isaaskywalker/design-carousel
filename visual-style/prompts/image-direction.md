# 프롬프트: 이미지 생성 방향 만들기

입력:
- style profile
- 슬라이드 목적
- 피사체/콘텐츠 요구사항

스타일 프로필에서 이미지와 관련된 규칙만 추출한다.

사용자에게 보여주는 결과는 한국어로 작성한다. 내부 이미지 생성 모델에 전달할 영문 표현은 `generation_keywords`에 분리한다.

```yaml
이미지_방향:
  피사체: "..."
  구성: "..."
  프레이밍: "..."
  조명: "..."
  배경: "..."
  질감: "..."
  색감: "..."
  피하기: []
  generation_keywords: []
```

이미지 안에 실제 텍스트를 렌더링해야 하는 경우가 아니라면 타이포/카피 규칙은 포함하지 않는다.

특정 살아있는 작가나 크리에이터의 스타일을 직접 모방하라고 지시하지 않는다. 대신 일반화된 시각 특성으로 변환한다.
