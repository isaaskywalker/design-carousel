# 프롬프트: 레퍼런스 분석

Pinterest 보드/핀, Instagram 계정/게시물, 스크린샷, 업로드 이미지, 로컬 이미지 폴더를 분석한다.

## 언어

- 기본 사용자-facing 언어: `ko-KR`
- 관찰, 설명, 신뢰도, 권장사항은 한국어로 작성한다.
- 생성 모델에 필요한 영문 키워드는 `generation_keywords`에만 별도로 기록한다.

## URL 우선 동작

1. 공개적으로 접근 가능한 시각 콘텐츠를 먼저 확인한다.
2. 실제로 발견/분석한 항목 수를 기록한다.
3. `source_status`, `discovered_items`, `analyzed_items`를 기록한다.
4. 제목, 소개, 캡션만으로 전체 시각 스타일을 추론하지 않는다.
5. 일부만 보이면 그 범위 안에서 분석하고 신뢰도를 낮춘다.
6. 차단되면 스크린샷이나 이미지 업로드를 요청한다.

## 분석 영역

- 타이포그래피
- 정렬
- 정보 위계
- 여백/밀도
- 구성
- 그리드
- 크롭
- 이미지 피사체
- 사진/일러스트 처리
- 색 사용
- 시각 모티프
- 텍스트 밀도
- 제목 길이
- 카피 리듬

각 관찰은 다음 형태로 작성한다.

```yaml
관찰: "구체적으로 반복되는 시각 패턴"
근거_수: 9
샘플_수: 12
신뢰도: 높음 | 중간 | 낮음
generation_keywords:
  - "optional English keyword"
```
