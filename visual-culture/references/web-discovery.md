# Codex 웹 탐색 계약
실제 사용 가능한 검색/브라우저 도구를 발견한 뒤 사용한다. 도구 이름이나 존재하지 않는 API를 가정하지 않는다. URL 요청은 공개 시각 자료를 우선 확인한다. 검색 텍스트만 읽었다면 이미지를 분석했다고 하지 않는다.
검색 로그에 status(not_attempted/success/partial/blocked/unavailable), query, attempted_at, opened_urls, inspected_asset_ids, limitation을 저장한다. 호출 실패도 기록한다. 도구가 없으면 not_attempted가 아니라 unavailable과 이유를 기록하며 검색했다고 표현하지 않는다.
최신 후보는 작업 날짜·독자 지역을 기준으로 주제+반응+인물/밈+최근 기간을 검색한다. 예: “한국 직장인 AI 야근 밈 최근”, “Korean reaction meme exhausted office worker”. 적은 후보로 시작하고 맥락이 부족할 때 확장한다.
검색 결과의 원본 페이지·미디어를 열고 실제 장면·원문·발생 날짜를 확인한다. 재게시 날짜를 밈 탄생일로 쓰지 않는다. 인기 주장은 독립적인 최근 사용 근거를 가능하면 둘 이상 확인하며 한 출처면 limited confidence라고 밝힌다. 임의의 기간만으로 유행을 확정하지 않는다.
로그인/비공개/anti-bot을 우회하지 않는다. 공개 프리뷰 일부만이면 partial. 자료가 충분하지 않으면 “공개 URL에서 이미지를 확인하지 못했습니다. 대표 스크린샷으로 분석을 이어갈 수 있어요.”라고 요청한다. 기존 업로드가 있으면 바로 사용한다. 검색 결과가 없어도 적합한 사용자 이미지를 쓸 수 있지만 ‘요즘 유행’ 검증은 미완료로 둔다.

한국어 콘텐츠의 밈 검색은 [한국 최신 밈 규칙](korean-current-memes.md)을 따른다. 한국어 주제·현재 연월로 국내 사용부터 찾는다. 위 영어 검색 예시는 국내 최신 탐색의 기본값이 아니다.
