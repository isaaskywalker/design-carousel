# 문화 자산을 반영한 레이아웃
## Contextual person + comments
실제 인물을 큰 배경 앵커로 놓고 댓글 캡처를 전경으로 배치한다. 얼굴/특징이 남는 크롭, 캡처의 원문 읽기, 제목→인물→댓글 순서를 확보한다. 캡처가 설명하면 중복 본문을 삭제한다. 약한 회전과 비대칭 겹침은 허용하지만 문장·작성자 관계를 오해시키지 않는다. 캡처 원본을 먼저 확보하고 글자를 AI로 다시 그리지 않는다.
## Kitsch person + emoji + animal
대형 실존 인물 컷아웃과 이모지·돌고래·스티커를 다른 크기/질감으로 결합한다. primary focal anchor를 유지하고 장식의 이유(반응/과장/뜬금없음)를 기록한다. 의도적 합성 느낌은 허용하되 얼굴·제목·정보를 가리지 않는다. 모든 장에 인물·이모지를 의무 추가하지 않는다.
## 공통
카피·레이아웃·자산을 함께 선택한다. 얼굴 보호 영역, crop/fit, z-order, 화면 밖 bleed/clip, 댓글 최소 가독 크기와 모바일 미리보기를 기록한다. 픽셀 수치와 자산 비율은 캔버스·실제 원본을 확인한 뒤 정한다. 스타일의 ‘한 개의 강한 초점’과 콜라주가 충돌하면 인물을 주초점, 장식을 보조초점으로 조정하고 근거를 남긴다.
