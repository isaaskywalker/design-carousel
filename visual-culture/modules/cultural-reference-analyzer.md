# Cultural Reference Analyzer
입력: 실제 확인 가능한 URL·이미지·스크린샷. 출력: culture-dna.json.
각 레퍼런스에 접근 상태(complete/partial/blocked), 실제 분석 수, 이미지별 근거 ID를 기록한다. 앱 탐색 버튼·좋아요 수 등 플랫폼 UI와 제작자가 합성한 콘텐츠 레이어를 분리한다.
인물/밈/댓글/장식의 역할(contextual_anchor/evidence/reaction/absurdity/emphasis), 크롭, 전후 관계, 겹침, 의도적 조악함, 문화적 훅을 관찰한다. 누구인지·왜 웃긴지 확실하지 않으면 unknown 또는 사용자 설명 기반 추론으로 남긴다. 사진만으로 신원을 확정하지 않는다.
사용자가 스윙스·원희라고 설명한 사례는 그 설명을 출처로 기록한다. 인물의 현재 유행 여부는 별도 웹 확인 전까지 미확인이다. 하나의 예시를 모든 슬라이드에 의무 적용하지 않는다.
관찰 예: “큰 인물 사진 앞에 흰 댓글 캡처 세 개가 흩어져 있으며, 얼굴 일부와 휴대폰이 보인다.” 규칙: “인물은 맥락 인지, 캡처는 설명을 맡게 하고 중복 본문을 줄인다.”
