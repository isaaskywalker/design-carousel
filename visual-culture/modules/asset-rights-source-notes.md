# Asset Rights / Source Notes
후보마다 source_page_url, original_media_url, creator, accessed_at, published_at, event_at, context, rights_status, rights_basis, usage_note, local_path를 기록한다. 모르면 null/unknown을 사용한다.
웹 공개와 사용 허가는 다르다. 출처 표기만으로 사용권을 확정하지 않는다. 권리 상태는 unknown/user_confirmed/licensed/permission_granted/restricted. 사용자 제공 자료도 권리 상태를 자동 승인하지 않는다. source_confidence와 rights_status는 별개다.
미확인 권리는 디자인 계획·내부 검토에서 명시하고, 배포용이면 허가 확인·적절한 라이선스 후보·사용자 소유 자료로 해결한다. 법률 판단을 단정하지 않는다. 실제 실행 환경이 제공하는 이미지 다운로드·표시 규칙을 따른다.
댓글은 원문 의미를 바꾸지 않고 필요한 부분만 자른다. 일반인 핸들·프로필·개인정보는 필요한 경우 가린다. 인물 콜라주가 협찬·추천·실제 발언을 오인시키면 문구·관계를 수정한다. reference_only 자산은 최종 배치하지 않는다.
AI 장식에는 실제 원본 URL을 만들어 붙이지 않는다. generation prompt/tool 메모를 남기고 실제 사진과 구분한다.
