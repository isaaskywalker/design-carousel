# 문화 슬라이드 계획 예시
이는 실제 제작/검색 결과가 아닌 구조 예시다. 사용자 설명의 인물 이름을 사용했고 현재 유행은 검증하지 않았다.

| 슬라이드 | 카피/역할 | 자산과 구성 | 실행 전 조건 |
|---|---|---|---|
| 댓글 말투 사례 | 제목 “댓글만 봐도 누군지 알겠네”, 본문 생략 | 스윙스 실제 원본을 맥락 배경으로 크게 크롭, 얼굴 특징을 남기고 실제 댓글 2~3개를 전경에 비대칭 배치, 강조 표시 | person-context와 comment-1 원본 확보, 원문 관계 확인, 개인정보 처리, 출처 노트 |
| 쉬운 캐러셀 제작 | 제목 “15분이면 나도 완성”, 짧은 보조 문구 | 현재성 확인을 거친 아이돌/유명인 실제 컷아웃을 크게, 노란 이모지와 돌고래/스티커를 서로 다른 크기와 질감으로 겹침 | idol-context 최신성 확인 또는 evergreen 처리, 각 사진/스티커 원본과 출처 확보 |

후자는 사용자가 원희라고 설명한 예시에서 출발한다. 새 작업에서 자동으로 원희를 선택하지 않고 독자·메시지·현재 근거에 맞는 후보를 평가한다. 예시 카피를 해당 인물의 실제 발언/추천으로 표시하지 않는다.
