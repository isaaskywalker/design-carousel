# 기본 제작 규칙

## 브랜드·툴 이름

툴·서비스를 소개하는 슬라이드에서는 일반 폰트로 브랜드 이름을 재현하기보다 실제 로고 또는 워드마크 자산을 우선한다. 사용자가 준 로고, 공식 브랜드 키트, 공식 웹사이트의 로고 순으로 확보하고 출처를 기록한다. 심볼과 워드마크가 함께 있는 원본이면 함께 보존한다. 배경에 맞는 공식 밝은/어두운 변형을 선택한다. 로고 자체에는 Pretendard 소제목 규격을 강제하지 않으며, 가독성과 시각적 크기를 맞추고 원본 비율·색상·여백을 유지한다. AI로 로고를 만들거나 비슷한 폰트로 쓴 이름을 공식 로고라고 주장하지 않는다. 확보할 수 없으면 텍스트 대체임을 기록한다. 주제와 관련 없는 로고를 장식으로 넣지 않는다.

사용자의 명시적 지정이 우선한다. 기본 캔버스는 1080×1350이다.

- 상단 Y=120, 하단 Y=1230에 Figma 편집용 가이드를 설정한다. 제목·본문·배지는 이 사이에 둔다. 배경과 장식 이미지만 bleed를 허용한다. 금지선을 결과 이미지에 그리지 않는다.
- 좌우 본문 여백은 104px이다. 이미지는 의미와 가독성에 맞춰 자유롭게 구성하되 주요 피사체는 안전 영역을 존중한다.
- 표지 대제목: Pretendard ExtraBold 95. 소제목: Pretendard Bold 57. 본문의 작은 텍스트: Pretendard Regular 35. Figma fontSize 수치는 각각 95·57·35로 설정한다. 실제 이미지 안에 이미 포함된 UI 글자는 이 규칙의 대상이 아니다.
- `1/5`, `⅕장` 등의 장수 표시는 넣지 않는다. 항목 번호는 내용상 필요할 때만 사용한다.
- 표지는 사용자가 제공한 `[Template]`의 검정 그라데이션 레이어를 확인해 기본 적용한다. 표지를 제외한 흰 배경 장표에는 검정 그라데이션을 자동 적용하지 않는다. 사진 위 오버레이가 필요한 경우에만 사진 영역 안에 제한해 사용하고 본문 배경은 흰색으로 유지한다. 원본의 fills·불투명도·변환·크기를 보존하여 복제하고, 사진 위·본문 아래에 둔다. 새 캔버스 크기에서는 비율에 맞춰 변환한다. 원본을 읽을 수 없다면 동일하다고 주장하지 않는다.
- 이번 검증 템플릿은 하단 573px 높이, 180도 회전, GRADIENT_LINEAR, paint opacity 0.84다. 검정 불투명 stop에서 투명 stop으로 전환한다. 표지의 그라데이션 위 글자는 흰색을 우선하고 실제 렌더에서 대비를 확인한다. 표지 외 본문은 검정 글자 규칙을 따른다.
- 규격 적용 후 실제 화면을 확인한다. 이미지 간격·줄바꿈·안전 영역·그라데이션 대비를 함께 수정한다. 기존 원본 템플릿은 변경하지 않는다.

## 메인 컬러

기본 테마 컬러는 #567D45이다. 사용자 지정이 우선한다. 강조 타이포·배지·항목 번호에 일관되게 적용하되 실제 브랜드 로고의 고유 색상은 유지한다.

## 표지와 본문 테마

- 표지: 제목·부제·설명 글자는 흰색(#FFFFFF)을 우선한다. 사진 또는 테마 컬러(#567D45) 배경에 충분한 대비를 확보하고, 필요하면 배경 오버레이를 조정한다. 글자를 테마 컬러로 칠하는 것은 기본값이 아니다. 사용자가 지정하거나 흰색 가독성이 확보되지 않는 경우에만 다른 색을 선택하고 이유를 기록한다.
- 표지 외 모든 장표: 기본 배경 #FFFFFF, 소제목·본문 기본 글자 #000000. 임의의 파스텔·테마색 전면 배경으로 바꾸지 않는다. 테마 컬러 #567D45는 배지·선·도형·제한된 강조에 사용한다. 색 배지 안의 글자는 해당 배경과의 대비를 기준으로 선택한다.
- 원본 사진·캡처·실제 브랜드 로고의 색상은 보존한다. 위 글자 규칙은 캐러셀에 작성한 텍스트에 적용하며 이미지 안의 글자를 다시 칠하지 않는다.
- 사용자의 명시적 슬라이드별 지정이 기본값보다 우선한다. 레퍼런스 색상이 이 기본 테마와 다르면 구조·타이포 문법을 참고하면서 사용자 테마를 적용한다. Critic은 표지의 흰 글자 대비와 본문 장표의 흰 배경·검정 글자를 확인한다.
