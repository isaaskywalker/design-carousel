# 사용자 시나리오

## 레퍼런스로 새 캐러셀
“$design-carousel로 첨부 레퍼런스의 에디토리얼 스타일을 반영해 집중력 팁 7장을 만들어줘. 한국어, 1080×1350. 필요한 이미지는 생성하고 이 Figma 파일에 새 프레임으로 만들어줘.”
스타일 분석 → 카피 → 유연한 배치 → 필요한 이미지 → Figma 구현 → 실제 렌더 평가.

## 기존 스타일 프로필 재사용
“이 visual-style 프로필로 신제품 소개 5장을 기획해줘. Figma 수정 없이 카피와 디자인 계획만.”
프로필 재사용, 5장 계획 납품. Figma 실행 생략.

## 고정 템플릿에서 전환
“기존 figma-carousel의 브랜드 서명과 캔버스는 유지하고 슬라이드마다 구도를 바꿔줘.”
브랜드와 사이즈는 제약, 좌표와 구도는 재설계. 실행기의 템플릿 제한을 확인하고 필요하면 직접 Figma 구현.

## 일부 장 수정
“3번 장의 카피를 절반으로 줄이고 이미지를 크게 해줘. 나머지는 그대로.”
대상 장의 계획과 프레임만 수정하고 읽는 순서·넘침을 재검증.

## 이미지 없이
“검정과 크림색, 큰 타이포만으로 6장. 이미지는 만들지 마.”
텍스트와 shape 요소로 구성하고 이미지 단계 생략.

## 연결 누락
“이 Pinterest 보드로 만들어줘”라는 요청에서 보드를 읽을 수 없으면 이미지 첨부/접근 가능한 자료가 필요함을 설명한다. 도구가 없는 단계는 계획 상태로 남기고 실행 완료를 주장하지 않는다.
