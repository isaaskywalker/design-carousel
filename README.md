# design-carousel + Visual Culture DNA
한국어 캐러셀을 위한 세 가지 독립 Codex 스킬. 기존 design-carousel의 모듈과 visual-style 자료를 보존하고 문화 분석을 추가했다. 이 ZIP은 설치용 패키지이며 자동 설치나 실제 캐러셀/Figma 제작을 수행하지 않는다.

- `visual-style/`: 타이포·색·여백·레이아웃의 형식적 Style DNA.
- `visual-culture/`: 인물·밈·댓글·이모지·스티커·동물과 콜라주 문법, 문화 자산 선정과 출처.
- `design-carousel/`: 카피·자산·레이아웃 공동 기획과 평가를 묶는 지휘 계층.

각 폴더의 SKILL.md를 독립 호출할 수 있다. visual-style은 기존 design-skill의 자료를 정규화한 배포 사본이며 원본 설치 파일은 변경하지 않았다. design-carousel 통합 실행 시 세 폴더를 같은 skills 디렉터리에 둔다. `$figma-carousel`은 별도 설치 의존성이며 이 ZIP에 포함하지 않는다. 없어도 분석/계획 납품은 가능하다.

문화 요소가 불필요하면 `visual-culture`를 생략한다. 사용자 이미지로 이어가는 경우에도 최신성 미확인을 그대로 기록하며, 실제로 하지 않은 검색이나 이미지 확인을 완료했다고 표현하지 않는다. `$figma-carousel`은 기획과 소재 선정을 대신하지 않는 실행 계층이다. 별도 스킬이 없으면 사용 가능한 Figma 도구와 필수 도구 스킬로 실행하거나, 연결이 불가능한 경우 계획 납품과 실제 제작 완료를 구분한다.

## 현재 기본 제작 규칙

명시적인 사용자 지정이 우선한다. 형식적 스타일 분석과 사용자 테마를 구별하고, 실제 브랜드 로고·사진의 고유 색상은 유지한다.

| 항목 | 기본값 |
| --- | --- |
| 언어 · 캔버스 | 한국어 · 1080×1350 |
| 테마 컬러 | `#567D45` |
| 표지 | 흰색 글자 `#FFFFFF` 우선, 배경과 대비 확보 |
| 표지 외 장표 | 흰 배경 `#FFFFFF` · 검정 글자 `#000000` |
| 표지 대제목 | Pretendard ExtraBold 95 |
| 소제목 | Pretendard Bold 57 |
| 본문의 작은 텍스트 | Pretendard Regular 35 |
| 안전 영역 | 좌우 104px · 상하 120px, 편집 가이드 Y=120·1230 |
| 장수 표시 | `1/5`, `⅕장` 등 표시하지 않음 |
| 툴 · 브랜드 이름 | 확보한 실제 로고·워드마크 우선, 원본 비율 유지 |
| 검정 그라데이션 | 제공된 템플릿을 확인해 표지에 기본 적용 |

서체 숫자는 Figma `fontSize` 값이다. 편집 가이드는 최종 이미지에 그리지 않는다. 배경·장식은 bleed가 가능하지만 주요 텍스트는 안전 영역에 둔다. 흰 배경 본문 장표에 검정 그라데이션을 자동 적용하지 않는다. 필요한 사진 오버레이는 사진 영역에 한정한다. 자세한 규칙은 [기본 제작 규칙](design-carousel/references/default-production-rules.md)에 있다.

### 한국 최신 밈·짤

한국어 콘텐츠는 **한국 시장 · 한국어 검색 · latest**를 기본으로 한다. 최근 30일 국내 사용을 우선 확인하고, 부족하면 90일까지 확장한다. 2026년 요청은 2026년 국내 사용 근거를 검증하며, 이후에도 실제 제작 날짜마다 조사한다. 고정된 '2026 밈 목록'을 계속 재사용하지 않는다.

가능한 한 독립적인 국내 최근 사용 2건으로 인지도와 유행을 뒷받침한다. 원본 발생일·최근 국내 사용일·조회 날짜를 구별한다. 오래된 해외 밈도 국내 재유행 근거가 확인되면 검토할 수 있지만, 익숙하다는 이유로 한국 최신 짤을 대신하지 않는다. 높은 점수로 국내 사용 근거 미확인을 덮지 않는다. 자료가 부족하면 사용자 이미지로 전환하거나 밈을 생략하고 한계를 한국어로 보고한다. [한국 최신 밈 규칙](visual-culture/references/korean-current-memes.md)

### 장표 간 이미지 중복 방지

표지를 포함한 전체 캐러셀에서 동일 원본 이미지는 한 장표에만 배정한다. 크롭·누끼·반전·색보정·리사이즈·콜라주 속 재사용도 중복이다. 다른 URL이나 파일명이 같은 사진을 별개 자산으로 만들지 않는다. 같은 인물·브랜드의 실제로 다른 사진이나 화면은 사용할 수 있다.

원본 ID와 파생 관계·사용 장표를 기록하고 파일 해시와 전체 렌더로 검수한다. 중복이 있으면 다른 원본을 찾거나 이미지 수를 줄인다. 공통 로고·워터마크·공통 UI 아이콘은 반복 가능하며, 사용자에게 명시적으로 요청받은 반복은 그 지시를 따른다. [이미지 중복 방지 규칙](design-carousel/references/unique-slide-images.md)

## 한국어 사용 시나리오
### 1. Pinterest URL에서 시작
“$design-carousel 이 Pinterest 보드 [내 공개 보드 URL]를 참고해서 AI 툴 과몰입 주제로 6장 만들어줘. 한국 직장인이 알아보는 밈을 쓰고 싶어.”
Codex는 실제 공개 이미지를 먼저 확인하여 Style DNA와 Visual Culture DNA를 따로 추출한다. 필요한 밈/반응 이미지를 한국어로 현재 웹에서 검색하고 국내 최근 사용 검증을 통과한 후보만 다섯 차원으로 평가한다. 표지와 본문에는 서로 다른 원본을 배정한다. 카피 길이·댓글 역할·크롭을 함께 계획하고 준비된 자산을 실행 계층에 전달한다. 렌더에서 Style/Culture Critic이 수정한다.

### 2. Instagram URL과 인물/댓글 콜라주
“$design-carousel 이 Instagram 게시물 [내 공개 게시물 URL]처럼 실제 인물을 뒤에 크게 놓고 댓글을 위에 얹어줘.”
URL이 막히면 이미 분석했다고 말하지 않고 대표 스크린샷으로 전환한다. 사용자 자료에서 문화적 구성과 형식적 구성을 각각 분석한다. 실제 작성자와 원본 댓글의 관계를 확인하고 댓글이 설명을 맡으면 본문을 줄인다. 최신 사례가 필요할 때만 실제 검색 근거를 추가한다.

### 3. 아이돌과 이모지/돌고래의 키치
“$design-carousel 원희 예시 같은 느낌으로, 지금 독자들이 알아볼 인물과 이모지·동물·스티커를 섞어서 만들어줘.”
‘지금’은 최신 검색으로 검증하고 원희를 자동 최신 후보로 확정하지 않는다. 실제 사진의 인지 효과를 유지하고 장식의 부조리와 크기 차이를 설계한다. [슬라이드 예시](design-carousel/examples/culture-slides.md)는 두 구성을 설명하는 계획이며 최신 후보 검색 결과가 아니다.

### 4. 웹 도구가 없을 때
“$visual-culture 첨부한 세 장을 분석해줘.”
검색 상태를 unavailable 또는 not_attempted로 정확히 기록한다. 업로드 이미지에서 근거를 뽑고 최신성은 미확인으로 둔다. 실제 사진과 AI 장식·재구성 캡처를 별도 provenance로 표시한다.

## 데이터와 모듈
visual-culture/modules에 Analyzer, Asset Director, Relevance Scorer, Rights/Source Notes, Culture Critic이 있다. schemas에는 DNA와 asset manifest가 있으며 references에는 웹 탐색·문화 레이아웃 규칙이 있다. examples의 null 점수와 pending 자산은 원본을 확보하지 않은 상태를 표현한다.
사용자에게 보여주는 분석·선정 이유·평가는 한국어다. JSON 키와 내부 generation_keywords는 영어로 유지 가능하다. 한국 최신 밈 탐색은 한국어 검색을 기본으로 하고, 영어 검색은 국내 유행이 확인된 소재의 원본 탐색 등 보조 용도로 사용한다. 출처 신뢰도는 사용 허가가 아니다. 가짜 댓글·AI 인물을 실제 자료로 표시하지 않는다.

## 설치 및 검증
ZIP을 풀어 `design-carousel/`, `visual-style/`, `visual-culture/` 세 폴더를 `~/.agents/skills/` 아래에 나란히 복사한다. 각 폴더 바로 안에 `SKILL.md`가 있어야 하며 패키지 부모 폴더 전체를 한 스킬로 넣지 않는다. 폴더가 없으면 터미널에서 `mkdir -p ~/.agents/skills`로 만든다. 다음 입력에서 `$design-carousel`로 호출하고, 목록에 나타나지 않으면 Codex를 재시작한다. 이 경로는 로컬 Codex용이며 GPT 등록을 자동으로 수행하지 않는다. 기존 같은 이름 폴더가 있다면 먼저 비교/백업하고 필요한 변경만 반영한다. 설치 폴더의 각 SKILL.md가 진입점이다. 세 스킬은 서로 다른 곳에도 재사용할 수 있지만 design-carousel 통합 사용은 이름으로 찾거나 동일 skills 부모에 둔다.
검증 도구는 Python jsonschema가 있는 환경에서 `python scripts/validate_package.py`로 실행한다. 스키마·예시·자산 참조와 점수 상태를 확인한다. 실제 웹 검색과 Figma 연결은 실행 환경에 따라 달라지며 이 패키지의 정적 검증이 그 성공을 보장하지 않는다.


## 주제 우선 디렉팅으로 개선
댓글·밈·유명인·누끼는 필수 레시피가 아니다. 주제와 각 장의 메시지에서 이미지 역할을 먼저 결정하고 실제 후보를 본 뒤 처리와 구성을 선택한다. 일반 이미지에는 문화적 인지도 점수를 강제하지 않는다.

### 논쟁 주제
“국제대회 금메달과 군 복무 특례가 타당한지 다뤄줘. 관련 인물 사진과 필요하면 댓글도 보여줘.”
사용자가 인물을 지목했더라도 사건 관련성·신원·현재 기사 맥락을 먼저 확인한다. 제도 설명은 공식 근거를 확인한다. 적합한 기사/경기 사진을 배경으로 선택하고 실제 댓글은 설명에 도움이 될 때만 선별한다. 과한 표현은 제외하며 공격적 댓글을 고쳐 실제 원문처럼 만들지 않는다. 댓글은 없거나 불필요하면 생략한다.

### 장소 소개
“이 카페를 소개해줘. 건물이나 위치가 보이고 디저트도 보여주면 좋겠어.”
실제 같은 지점의 외관/내부 사진을 공간 앵커로 선택하고 실제 메뉴 사진을 보조 배치한다. 두 장은 시작 예시이며 정보량에 맞춰 조정한다. 공간 사진은 배경을 살리고, 디저트는 사진 프레임 또는 누끼 중 원본에 맞게 결정한다. 관련 없는 연예인이나 댓글은 추가하지 않는다.

### 탐색과 편집
Google 등의 검색 결과에서 발견해도 기사/Instagram 원본으로 이동해 실제 이미지와 맥락을 확인한다. 원본 사용·크롭·누끼·콜라주를 자율 선택하고 편집 도구가 없으면 미처리 계획으로 남긴다. 실제 확보하지 않은 기사 이미지나 사진 경로를 만들지 않는다.
